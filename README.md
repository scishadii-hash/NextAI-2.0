# NextAI 2.0 — Starter

نسخة تأسيسية نظيفة: واجهة دردشة + FastAPI + اتصال قابل لتغيير نموذج Gemini.

## التشغيل محلياً
1. Python 3.10+
2. `pip install -r requirements.txt`
3. اضبط متغير البيئة `GEMINI_API_KEY`
4. شغّل: `uvicorn app:app --reload`
5. افتح `http://127.0.0.1:8000`

## النشر على Render
1. ارفع محتويات المجلد إلى مستودع GitHub جديد.
2. في Render اختر New → Web Service ثم اربط المستودع.
3. Render سيقرأ إعدادات `render.yaml`.
4. من Environment أضف `GEMINI_API_KEY` بقيمة المفتاح الخاص بك.
5. Deploy.

اختياري: أضف `GEMINI_MODEL` لتغيير اسم النموذج دون تعديل الكود.

## ملاحظات
- لا تضع مفتاح API داخل الكود أو GitHub.
- الخطة المجانية قد تدخل في وضع الخمول، وقد يكون نظام الملفات مؤقتاً؛ لذلك لا نعتمد عليها لحفظ الذاكرة الدائمة.
- هذه المرحلة لا تنفذ أوامر على الجهاز ولا تعدّل ملفات المستخدم. الأدوات والذاكرة الدائمة ستضاف بعد اختبار الأساس.
